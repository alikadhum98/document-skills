# ملفات إعداد المؤتمرات

لكل مؤتمر أو دورة مجلد باسمه فيه `conference.json`. وهو المصدر الوحيد للمعرفات والمواعيد والنطاق، فتقرأ منه المهارات والمهام المجدولة بدل أن تكتب المعرفات داخلها.

## الحقول

١. `id` و`title` و`city` و`start` و`end` و`timezone`: هوية المؤتمر ومنطقته الزمنية، وعليها تبنى المهام المجدولة.
٢. `status`: planned قبل البدء، وactive أثناءه، وclosed بعد الختام.
٣. `scope`: الملفات التفاوضية التي يتابعها المستخدم، والتحالفات التي ينسق معها، وتاريخ بدء التنسيق.
٤. `alliance_priority`: ترتيب التحالفات عند الاختلاف.
٥. `drive`: مجلد المؤتمر ومجلدات أيامه والمجلدات المغلقة لكل تحالف.
٦. `files`: أسماء مرجع المداخلات وملفات الواتساب وملفات المواقف المغلقة وملفات الأذن.
٧. `sessions`: المحادثة الرئيسية والفرعيات ونطاق كل منها.
٨. `triggers`: المهام المجدولة للصباح والمساء والمتابعة.
٩. `repo`: مسارات التقارير في المستودع.

## الاستعمال

١. ينشئ المجلد والملف بكلمة (ابدأ مؤتمر) ثم الاسم، من القالب في `_template`.
٢. يغلق بكلمة (اختم المؤتمر)، فيصير `status` closed وتوقف المهام المجدولة.
٣. ملفات COP31 بقيت في مجلد `cop31` في جذر المستودع، ويحيل إليها `COP31/conference.json`. والمؤتمرات الجديدة تحفظ تقاريرها داخل مجلدها هنا.
