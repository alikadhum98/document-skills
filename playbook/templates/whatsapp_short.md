# رسالة قصيرة

## متى

خبر سريع لزميل أو مسؤول أو كروب، حين يطلب المستخدم رسالة قصيرة أو ملخصة جدا.

## القواعد

١. سطران أو ثلاثة.
٢. لا ترقيم ولا عناوين ولا رموز، كأنها كتبت باليد.
٣. الخبر الأهم أولا، ثم ما يليه.
٤. لا عبارات مثل (أود إعلامكم) أو (يسرني).

## النموذج

```
انتهت [الجلسة] [الليلة] و[النتيجة الأهم]، و[ما يستمر وأين].
وفي [البند الثاني] [ما جرى بسطر]، و[ما يليه].
```
