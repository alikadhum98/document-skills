# مكتبة النماذج

نماذج مجربة من COP31، تبدأ منها الكتابة بدل البدء من الصفر. والخانات بين أقواس معقوفة [ ] تملأ قبل النسخ، وينبه عليها فوق النص كما في قاعدة الكتابة الرابعة.

١. `whatsapp_group_session.md`: رسالة الكروب التفاوضي عن جلسة.
٢. `whatsapp_closing.md`: رسالة الجلسة الختامية.
٣. `whatsapp_short.md`: رسالة قصيرة بسطرين أو ثلاثة.
٤. `whatsapp_plain.md`: رسالة لغير المختصين بلغة سهلة.
٥. `coordinator_message.md`: رسالة منسق المجموعة العربية.
٦. `intervention_short.md`: مداخلة قصيرة بنبرة القاعة.
٧. `facebook_post.md`: منشور أو خبر لصفحة شخصية أو رسمية.
٨. `statement_assessment.md`: تقييم بيان صحفي أو وثيقة في حدود الاختصاص.
٩. `final_report_outline.md`: هيكل التقرير النهائي للمؤتمر.

يضاف إلى المكتبة كل نص يعتمده المستخدم بعد تعديله، بعد حذف ما فيه من محتوى مغلق.
