# تدابير الاستجابة والتجارة

اتفاقات كانكون 1/CP.16، الحصيلة العالمية 1/CMA.5، قرار بيليم، منتدى تدابير الاستجابة، حوارات التدابير التجارية الأحادية.

## الوثائق المطلوب تنزيلها إلى Drive

١. اتفاقات كانكون، المقرر 1/CP.16، الوثيقة FCCC/CP/2010/7/Add.1.
٢. نتيجة الحصيلة العالمية الأولى، المقرر 1/CMA.5، الوثيقة FCCC/PA/CMA/2023/16/Add.1.
٣. قرار بيليم (Global Mutirão)، مؤتمر الأطراف الثلاثون ٢٠٢٥.

## تسلسل الصياغة الخاصة بالتدابير الأحادية

ترد صياغة (التدابير المتخذة لمكافحة تغير المناخ، بما فيها الأحادية، ينبغي ألا تشكل وسيلة للتمييز التعسفي أو غير المبرر أو تقييدا مقنعا للتجارة الدولية) في:

١. المادة ٣ الفقرة ٥ من الاتفاقية الإطارية، ١٩٩٢.
٢. الحصيلة العالمية الأولى 1/CMA.5 الفقرة ١٥٤، دبي ٢٠٢٣.
٣. بيان فريق عمل مجموعة العشرين الوزاري وإعلان قادة ريو دي جانيرو، ٢٠٢٤.
٤. قرار بيليم، الفقرة ٥٦ بحسب النص الذي زوده المستخدم، ٢٠٢٥.

درجات التحقق لكل موضع في `../agreed_language.json`.
