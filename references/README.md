# المكتبة المرجعية للتفاوض

هيكل هذا المجلد مطابق لمجلد Negotiation-References في Google Drive. الوثائق الرسمية نفسها تحفظ في Drive، ويحفظ هنا وصف كل موضوع وقائمة وثائقه وسجل اللغة المتفق عليها.

## الموضوعات

١. `Core`: المراجع الأساسية المشتركة. الاتفاقية الإطارية، اتفاق باريس، بروتوكول كيوتو، إعلان ريو بشأن البيئة والتنمية.
٢. `Mitigation`: التخفيف. برنامج عمل التخفيف، مقررات المساهمات المحددة وطنيا ومعلوماتها.
٣. `Article6`: المادة السادسة. مقررات المادة ٦ الفقرة ٢ والفقرة ٤ والفقرة ٨ ومقررات تشغيلها.
٤. `Transparency`: الشفافية والإبلاغ والجرد. إجراءات وطرائق ومبادئ الإبلاغ، تقارير السنتين، إرشادات الجرد الوطني.
٥. `Finance`: التمويل. المادة ٩ من اتفاق باريس، الهدف الكمي الجماعي الجديد، مقررات الصناديق.
٦. `Adaptation`: التكيف. الهدف العالمي للتكيف، خطط التكيف الوطنية.
٧. `LossDamage`: الخسائر والأضرار. آلية وارسو الدولية، مقررات صندوق الاستجابة للخسائر والأضرار.
٨. `ResponseMeasures-Trade`: تدابير الاستجابة والتجارة. اتفاقات كانكون 1/CP.16، الحصيلة العالمية 1/CMA.5، قرار بيليم، منتدى تدابير الاستجابة، حوارات التدابير التجارية الأحادية.
٩. `GST-JustTransition`: الحصيلة العالمية والانتقال العادل. نتيجة الحصيلة العالمية الأولى، برنامج عمل الانتقال العادل.
١٠. `External`: المحافل الخارجية. وثائق الجمعية العامة، مجموعة العشرين، منظمة التجارة العالمية، الأونكتاد.

## ملفات السجل

١. `agreed_language.json`: سجل اللغة المتفق عليها، وتوضح درجات التحقق في ملف CLAUDE.md.
٢. `open_items.md`: البنود المعلقة التي تنتظر التحقق أو التنزيل.
